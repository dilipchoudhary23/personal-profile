## ▶️ Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project folder:

```bash
cd dilip-haritwal-portfolio
```

Then open `index.html` in any modern web browser.

No installation or build process is required.

## 🚀 Deploy with GitHub Pages

1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Select the `main` branch.
5. Select the root folder `/`.
6. Click **Save**.
7. GitHub will generate a public website URL for your portfolio.
